# 📱 CalorieCalculator - Frontend

基于 Taro 和 React 构建的跨端健康应用前端（当前编译目标：微信小程序）。通过动态交互实现卡路里与宏量营养素的可视化计算。

## 🛠️ 技术栈 (Tech Stack)
- **核心框架:** Taro 3.x + React
- **样式预处理:** Sass
- **运行环境:** 微信开发者工具

## 🚀 快速启动 (Quick Start)

### 1. 环境准备
- Node.js (推荐 v18+)
- 微信开发者工具

### 2. 安装依赖
由于网络环境差异，推荐使用 npm 官方源安装：
```bash
npm install --registry=[https://registry.npmjs.org/](https://registry.npmjs.org/)

#### 3.启动开发模式
npm run dev:weapp
